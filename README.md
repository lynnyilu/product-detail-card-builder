# Product Detail Card Builder

一个纯前端的小工具，用来制作淘宝 / 电商详情页里常用的「白底 + 文字」产品介绍图。不需要安装任何东西，用浏览器打开 `index.html` 就能用。

## 功能

- **所见即所得编辑**：标题、副标题、要点、各个板块（用法、注意事项等）都可以直接点击文字编辑，随时增删要点和板块
- **半透明水印**：可自定义水印文字、透明度、字号，斜向平铺覆盖在图片上
- **导出图片**：一键导出为高清 PNG（针对手机端详情页阅读做了字号/宽度比例调整）
- **保存 / 打开草稿**：把当前编辑内容保存为 `.json` 文件，下次打开继续编辑，不用重新输入
- 导出的图片和草稿文件名会自动使用产品标题作为文件名

## 使用方法

1. 用浏览器直接打开 `index.html`（双击文件，或右键"用浏览器打开"）
2. 点击卡片里的文字进行编辑
3. 根据需要点击「+ 要点」「+ 板块」增加内容
4. 在水印设置栏调整水印文字/透明度/字号
5. 编辑完成后点击「导出为图片」，生成的 PNG 就是最终成品图
6. 需要下次继续修改时，先点「保存文件」存一份 `.json` 草稿；下次打开 `index.html` 后点「打开文件」加载回来即可

## 技术说明

纯静态单文件（HTML + CSS + JavaScript），依赖：
- [html2canvas](https://html2canvas.hertzen.com/)（通过 CDN 引入，用于将卡片渲染导出为图片）
- Google Fonts：Noto Serif SC / Noto Sans SC

没有后端、没有构建步骤，克隆下来直接用即可。
